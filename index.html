A bounded statement

Reference commitment, candidate, trace capacity and statistics are bound. Model provenance, tokenization and benchmark manifest authenticity remain external responsibilities.

Benchmark privacy scope: Historical measurements use salts derived from public item identifiers. Those reference commitments are reproducible and non-hiding. Deployments require fresh secret random salts; these measurements do not establish commitment confidentiality.

Verification needs the owner’s commitment

A valid proof for a substituted reference can pass internal verification. Deployment must use verify_committed_statement with an independently authenticated digest fixed before evaluation.
